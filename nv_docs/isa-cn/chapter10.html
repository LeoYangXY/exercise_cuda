第 10 章 特殊寄存器（Special Registers）

PTX 包含若干预定义的只读变量，它们作为特殊寄存器（special register）可见，并通过 mov 或 cvt 指令访问。

术语说明：特殊寄存器是由硬件维护的只读寄存器，对应 CUDA 的 built-in variable（内建变量），例如 %tid（对应 threadIdx）、%ntid（对应 blockDim）、%ctaid（对应 blockIdx）、%nctaid（对应 gridDim）、%laneid（线程在 warp 内的编号）、%warpid（warp 编号）等。下文逐一说明每个寄存器的含义及其对应的 CUDA built-in。

特殊寄存器列表如下：

%tid · %ntid · %laneid · %warpid · %nwarpid · %ctaid · %nctaid · %smid · %nsmid · %gridid · %is_explicit_cluster · %clusterid · %nclusterid · %cluster_ctaid · %cluster_nctaid · %cluster_ctarank · %cluster_nctarank · %lanemask_eq / %lanemask_le / %lanemask_lt / %lanemask_ge / %lanemask_gt · %clock / %clock_hi / %clock64 · %pm0…%pm7 · %pm0_64…%pm7_64 · %envreg0…%envreg31 · %globaltimer / %globaltimer_lo / %globaltimer_hi · %reserved_smem_offset_begin / %reserved_smem_offset_end / %reserved_smem_offset_cap / %reserved_smem_offset_<2> · %total_smem_size · %aggr_smem_size · %dynamic_smem_size · %current_graph_exec

10.1. 特殊寄存器：%tid

%tid

线程在 CTA（Collaborative Thread Array，协作线程数组，相当于 CUDA 的线程块 block）内的标识符。对应 CUDA 的 built-in 变量 threadIdx。

语法（预定义）
.sreg .v4 .u32 %tid;                  // thread id vector
.sreg .u32 %tid.x, %tid.y, %tid.z;    // thread id components
说明

一个预定义的、只读的、每线程特殊的寄存器，初始化为线程在 CTA 内的标识符。 特殊寄存器 %tid 包含一个 1D、2D 或 3D 向量以匹配 CTA 的形状；未使用维度上的 %tid 值为 0。 第四个分量未被使用，始终返回 0。 每个维度上的线程数量由预定义的特殊寄存器 %ntid 指定。

CTA 内的每个线程都有唯一的 %tid。

在每个 CTA 维度上，%tid 各分量取值范围为 0 到 %ntid-1。

在 1D CTA 中，%tid.y == %tid.z == 0。 在 2D CTA 中，%tid.z == 0。

保证满足以下关系：

0  <=  %tid.x <  %ntid.x
0  <=  %tid.y <  %ntid.y
0  <=  %tid.z <  %ntid.z
PTX ISA 版本说明

于 PTX ISA 1.0 版本引入，类型为 .v4.u16。

在 PTX ISA 2.0 版本中重新定义为 .v4.u32 类型。 为兼容旧的 PTX 代码，可使用 16 位的 mov 和 cvt 指令读取 %tid 各分量的低 16 位。

目标架构说明

在所有目标架构上均受支持。

示例
mov.u32      %r1,%tid.x;  // move tid.x to %rh

// legacy code accessing 16-bit components of %tid
mov.u16      %rh,%tid.x;
cvt.u32.u16  %r2,%tid.z;  // zero-extend tid.z to %r2

10.2. 特殊寄存器：%ntid

%ntid

每个 CTA 的线程 ID 数量，即线程块的维度。对应 CUDA 的 built-in 变量 blockDim。

语法（预定义）
.sreg .v4 .u32 %ntid;                   // CTA shape vector
.sreg .u32 %ntid.x, %ntid.y, %ntid.z;   // CTA dimensions
说明

一个预定义的只读特殊寄存器，初始化为每个 CTA 维度上的线程 ID 数量。 特殊寄存器 %ntid 包含一个 3D CTA 形状向量，保存 CTA 的各维度大小。 CTA 各维度大小均非零；第四个分量未被使用，始终返回 0。 一个 CTA 内的线程总数为 (%ntid.x * %ntid.y * %ntid.z)。

%ntid.y == %ntid.z == 1 in 1D CTAs.
%ntid.z ==1 in 2D CTAs.

%ntid.{x,y,z} 的最大值如下：

.target architecture%ntid.x%ntid.y%ntid.z
sm_1x51251264
sm_20, sm_3x, sm_5x, sm_6x, sm_7x, sm_8x, sm_9x, sm_10x, sm_12x1024102464
PTX ISA 版本说明

于 PTX ISA 1.0 版本引入，类型为 .v4.u16。

在 PTX ISA 2.0 版本中重新定义为 .v4.u32 类型。 为兼容旧的 PTX 代码，可使用 16 位的 mov 和 cvt 指令读取 %ntid 各分量的低 16 位。

目标架构说明

在所有目标架构上均受支持。

示例
// compute unified thread id for 2D CTA
mov.u32  %r0,%tid.x;
mov.u32  %h1,%tid.y;
mov.u32  %h2,%ntid.x;
mad.u32  %r0,%h1,%h2,%r0;

mov.u16  %rh,%ntid.x;      // legacy code

10.3. 特殊寄存器：%laneid

%laneid

线程在 warp 内的通道（lane）编号。对应 CUDA 的 built-in 变量（可通过 threadIdx.x % warpSize 计算）。

语法（预定义）
.sreg .u32 %laneid;
说明

一个预定义的只读特殊寄存器，返回线程在 warp 内的 lane（通道）编号。 lane 编号取值范围为 0 到 WARP_SZ-1（WARP_SZ 为 warp 大小，通常为 32）。

PTX ISA 版本说明

于 PTX ISA 1.3 版本引入。

目标架构说明

在所有目标架构上均受支持。

示例
mov.u32  %r, %laneid;

10.4. 特殊寄存器：%warpid

%warpid

warp（线程束）标识符。一个 warp 内的所有线程具有相同的 %warpid。

语法（预定义）
.sreg .u32 %warpid;
说明

一个预定义的只读特殊寄存器，返回线程所属 warp 的标识符。 warp 标识符在单个 CTA 内是唯一的，但不能跨 CTA（同一网格内不同 CTA 之间不唯一）。 同一 warp 内的所有线程具有相同的 warp 标识符。

注意：%warpid 返回的是读取那一刻线程所在的位置，但其值在运行过程中可能发生变化，例如线程因抢占而被重新调度之后。 因此，如果内核代码中需要“虚拟 warp 索引”，应使用 %ctaid 和 %tid 来计算；%warpid 主要用于让性能分析和诊断代码采样并记录诸如工作位置映射、负载分布等信息。

PTX ISA 版本说明

于 PTX ISA 1.3 版本引入。

目标架构说明

在所有目标架构上均受支持。

示例
mov.u32  %r, %warpid;

10.6. 特殊寄存器：%ctaid

%ctaid

线程网格（grid）内的 CTA 标识符，即线程块在网格中的索引。对应 CUDA 的 built-in 变量 blockIdx。

语法（预定义）
.sreg .v4 .u32 %ctaid;                      // CTA id vector
.sreg .u32 %ctaid.x, %ctaid.y, %ctaid.z;    // CTA id components
说明

一个预定义的只读特殊寄存器，初始化为线程网格（CTA grid）内 CTA 的标识符。 特殊寄存器 %ctaid 包含一个 1D、2D 或 3D 向量，取决于 CTA 网格的形状与秩（维度数）。 第四个分量未被使用，始终返回 0。

保证满足以下关系：

0  <=  %ctaid.x <  %nctaid.x
0  <=  %ctaid.y <  %nctaid.y
0  <=  %ctaid.z <  %nctaid.z
PTX ISA 版本说明

于 PTX ISA 1.0 版本引入，类型为 .v4.u16。

在 PTX ISA 2.0 版本中重新定义为 .v4.u32 类型。 为兼容旧的 PTX 代码，可使用 16 位的 mov 和 cvt 指令读取 %ctaid 各分量的低 16 位。

目标架构说明

在所有目标架构上均受支持。

示例

mov.u16  %rh,%ctaid.y;   // legacy code

10.8. 特殊寄存器：%smid

%smid

SM（Streaming Multiprocessor，流多处理器）标识符，表示线程当前执行所在的 SM 编号。

语法（预定义）
.sreg .u32 %smid;
说明

一个预定义的只读特殊寄存器，返回某个特定线程正在其上执行的 SM（流多处理器）标识符。 SM 标识符取值范围为 0 到 %nsmid-1。 SM 标识符的编号不保证连续。

注意事项

注意：%smid 返回的是读取那一刻线程所在的位置，但其值在运行过程中可能发生变化，例如线程因抢占而被重新调度之后。 %smid 主要用于让性能分析和诊断代码采样并记录诸如工作位置映射、负载分布等信息。

PTX ISA 版本说明

于 PTX ISA 1.3 版本引入。

目标架构说明

在所有目标架构上均受支持。

示例
mov.u32  %r, %smid;

10.9. 特殊寄存器：%nsmid

%nsmid

SM 标识符的最大数量（设备上 SM 数量的保守上界）。

语法（预定义）
.sreg .u32 %nsmid;
说明

一个预定义的只读特殊寄存器，返回 SM 标识符的最大数量。 The SM identifier numbering is not guaranteed to be contiguous, 因此 %nsmid 可能大于设备上 SM 的物理数量。

PTX ISA 版本说明

于 PTX ISA 2.0 版本引入。

目标架构说明

%nsmid 需要 sm_20 或更高版本。

示例
mov.u32  %r, %nsmid;

10.10. 特殊寄存器：%gridid

%gridid

网格（grid）的标识符，用于区分不同次启动的网格。

语法（预定义）
.sreg .u64 %gridid;
说明

一个预定义的只读特殊寄存器，初始化为每网格的时间性网格标识符。 调试器可用 %gridid 来区分并发（小型）网格中的 CTAs 和 clusters。

在执行过程中可能会发生程序的重复启动，每一次启动都会开启一个“CTA 网格”。 该变量为本上下文（context）提供时间性的网格启动序号。

对于 sm_1x 目标，%gridid 的取值范围限定为 [0..2^16-1]；对于 sm_20，限定为 [0..2^32-1]；sm_30 支持完整的 64 位范围。

PTX ISA 版本说明

于 PTX ISA 1.0 版本引入，类型为 .u16。

在 PTX ISA 1.3 版本中重新定义为 .u32 类型。

在 PTX ISA 3.0 版本中重新定义为 .u64 类型。

为兼容旧的 PTX 代码，可使用 16 位和 32 位的 mov 与 cvt 指令读取 %gridid 各分量的低 16 位或低 32 位。

目标架构说明

在所有目标架构上均受支持。

示例
mov.u64  %s, %gridid;  // 64-bit read of %gridid
mov.u32  %r, %gridid;  // legacy code with 32-bit %gridid

10.23. 特殊寄存器：%clock, %clock_hi

%clock, %clock_hi

一个预定义的只读 32 位无符号周期计数器。

即 %clock64 特殊寄存器的低 32 位 / 高 32 位部分。

语法（预定义）
.sreg .u32 %clock;
.sreg .u32 %clock_hi;
说明

特殊寄存器 %clock 与 %clock_hi 是无符号 32 位只读周期计数器，溢出时静默回绕（wrap）。

PTX ISA 版本说明

%clock 于 PTX ISA 1.0 版本引入。

%clock_hi 于 PTX ISA 5.0 版本引入。

目标架构说明

%clock 在所有目标架构上均受支持。

%clock_hi 需要 sm_20 或更高版本。

示例
mov.u32 r1,%clock;
mov.u32 r2, %clock_hi;

10.27. 特殊寄存器：%envreg<32>

%envreg<32>

%reserved_smem_offset_begin, %reserved_smem_offset_end, %reserved_smem_offset_cap, %reserved_smem_offset_<2>

保留共享内存区域的起始偏移。

保留共享内存区域的结束偏移。
