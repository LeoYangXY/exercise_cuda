13.1 PTX ISA 9.3 版本变更

对应架构 / CUDA 背景：随 CUDA 13.3（driver r610）发布；Target 仍覆盖 sm_90(Hopper) 至 sm_121(Blackwell 后续)。本版本偏向集群通信与内存一致性的扩展。

PTX ISA 9.3 引入以下新特性：

  • 新增 mma_throughput pragma（pragma 指令，用于向编译器提示矩阵乘加的吞吐目标，辅助调度）。
  • 新增 clmad 指令（cluster-level 的乘加类指令，作用于线程块集群范围）。
  • mbarrier.test_wait 与 mbarrier.try_wait 新增 .phase_type::* 限定符（用于指定要等待的相位类型）。
  • 上述两条 mbarrier 等待指令新增 reportPredicate 与 reportValue 操作数（可将等待结果以谓词 / 数值形式报告出来）。
  • mbarrier 指令新增 .layout 限定符，并新增 mbarrier.check_layout 指令（用于检查 barrier 对象的内存布局是否匹配）。
  • 新增 multimem.st.async 与 multimem.red.async 指令（multimem 地址空间上的异步存储 / 异步归约，常用于多播集群场景）。
  • cp.async.bulk、cp.reduce.async.bulk、multimem.cp.async.bulk、multimem.cp.reduce.async.bulk 新增 .sem 与 .scope 限定符（语义 / 作用域控制）。
  • 新增 fabric.try_get/try_put/try_red/try_pullred/wait/submit 一组指令（fabric 即芯片内互联 fabric，用于跨 chiplet / 跨 GPU 的一致内存访问与归约）。
  • fence 指令新增 fence.proxy.to_proxykind::from_proxykind_fabric 限定符（在 fabric 代理间做 fence）。
  • 新增 .language 指令（声明 PTX 源所用的高级语言，辅助调试信息生成）。

语义变更与澄清

  • 澄清 red.async 指令支持 sys 作用域，但配合 .release 限定符时不支持 cluster 作用域。

13.2 PTX ISA 9.2 版本变更

对应架构 / CUDA 背景：随 CUDA 13.2（driver r595）。延续对 FP8 / 微缩放（micro-scaling）格式的完善，并为 sm_120(Blackwell) 增加 8 位打包整型算术。

PTX ISA 9.2 引入以下新特性：

  • add、sub、min、max、neg 指令新增 .u8x4 与 .s8x4 类型（4 路 8 位打包整数运算，配合 Blackwell 的 NVFP4 等低精度数据路径）。
  • 新增 add.sat.{u16x2/s16x2/u32} 指令（带饱和的加法，避免溢出）。
  • st.async 指令新增 .b128 类型（异步存储支持 128 位）。
  • cp.async.bulk 新增 .ignore_oob 限定符（越界访问时忽略而非报错，用于边界不整齐的批量拷贝）。
  • cvt 指令新增 .bf16x2 目标类型，源类型支持 .e4m3x2、.e5m2x2、.e3m2x2、.e2m3x2、.e2m1x2（FP8 系列格式互转）。

语义变更与澄清

  • 对于 wgmma.mma_async，当 .atype/.btype 为 .e4m3/.e5m2 且 .dtype 为 .f32 时，当前实现以高于半精度但低于单精度的精度进行累加。

13.3 PTX ISA 9.1 版本变更

对应架构 / CUDA 背景：随 CUDA 13.1（driver r590）。继续扩展 FP8 转换、微缩放向量，并引入 multimem 批量拷贝。

PTX ISA 9.1 引入以下新特性：

  • ld/st 在 .local 状态空间新增 .volatile 限定符。
  • cvt 新增 .f16x2 与 .bf16x2 源类型，目标类型为 .e2m1x2、.e2m3x2、.e3m2x2、.e4m3x2、.e5m2x2。
  • mma/mma.sp 在使用 .kind::mxf4nvf4 时，新增 .scale_vec::4X 且以 .ue8m0 作为 .stype。
  • cvt 新增 .s2f6x2 指令类型（FP6 相关转换）。
  • 新增 multimem.cp.async.bulk 与 multimem.cp.reduce.async.bulk 指令（multimem 地址空间上的批量异步拷贝 / 带归约的批量拷贝）。

语义变更与澄清

无。

13.4 PTX ISA 9.0 版本变更

对应架构 / CUDA 背景：随 CUDA 13.0（driver r580）。新增 sm_110 系列（对应 Blackwell 后续核心）、sm_88( Ada 后续)；引入 shared memory 溢出、基本块频率等编译指示。

PTX ISA 9.0 引入以下新特性：

  • 新增 sm_88 目标架构。
  • 新增 sm_110 目标架构。
  • 新增支持系列级特性的目标 sm_110f。
  • 新增支持架构级特性的目标 sm_110a。
  • 新增 pragma enable_smem_spilling，用于开启函数的 shared memory 溢出（spilling）到其它存储。
  • 新增 pragma frequency，用于指定基本块的执行频率（辅助调度 / 优化）。
  • 新增指令 .blocksareclusters，用于声明 CUDA 线程块被映射到集群（cluster）。
  • 扩展 st.bulk 指令的 size 操作数，支持 32 位长度。
  • 新增性能调优指令 .abi_preserve 与 .abi_preserve_control，用于指定函数调用方应保留的数据 / 控制寄存器数量。

说明

  • 从 PTX ISA 9.0 起，目标 sm_{101,101f,101a} 更名为 sm_{110,110f,110a}。

语义变更与澄清

  • 同一 kernel 内所有 tcgen05 指令（alloc/dealloc/relinquish_alloc_permit/cp/shift/mma/mma.sp/mma.ws/mma.ws.sp/commit）必须指定相同的 .cta_group 限定符值。

13.5 PTX ISA 8.8 版本变更

对应架构 / CUDA 背景：随 CUDA 12.9（driver r575）。引入“系列级”目标（带 f 后缀，兼容同系列后续芯片）：sm_100f/101f/103f/120f/121f；新增 sm_103、sm_121；tcgen05 持续扩展。

PTX ISA 8.8 引入以下新特性：

  • 新增 sm_103 目标架构及架构级目标 sm_103a。
  • 新增 sm_121 目标架构及架构级目标 sm_121a。
  • 引入系列级目标架构（以 “f” 后缀表示）；同一系列内后续芯片兼容该系列级 PTX。新增 sm_100f、sm_101f、sm_103f、sm_120f、sm_121f。
  • 扩展 min/max 指令支持三个输入操作数。
  • 扩展 tcgen05.mma：新增 .block16/.block32 的 scale_vectorsize 限定符，以及 K 维度 96。
  • 扩展 tensormap.replace 的 .field3 支持 96B swizzle 模式。
  • 新增 tcgen05.ld.red 指令（带归约的 tensor 内存加载）。
  • 扩展 ld、ld.global.nc、st 支持 256 位加载 / 存储。

表 64 系列级目标支持的特性

下列特性在系列级目标上可用（节选）：ldmatrix/stmatrix 的 .m16n8/.m16n16/.m8n16 与 .b8；tcgen05 多种形状；setmaxnreg；.cta_group；cvt 微缩放格式；multimem 的 .acc::f16 及 FP8 类型；tensormap.replace；tcgen05.ld.red（sm_101f/sm_103f）；各类 tcgen05 指令与 mma；clusterlaunchcontrol.try_cancel；redux.f32（sm_100f）等。

语义变更与澄清

  • 澄清 NaN 输入时浮点转整型转换的行为。

13.6 PTX ISA 8.7 版本变更

对应架构 / CUDA 背景：随 CUDA 12.8（driver r570）。新增 sm_120(Blackwell 架构级目标 sm_120a)；FP8 矩阵乘与微缩放持续扩展。

PTX ISA 8.7 引入以下新特性：

  • 新增 sm_120 目标架构及架构级目标 sm_120a。
  • 扩展 tcgen05.mma：新增 .kind::mxf4nvf4 与 .scale_vec::4X 限定符。
  • 扩展 mma 指令：支持 .f16 累加器、形状 .m16n8k16，以及 FP8 类型 .e4m3/.e5m2。
  • 扩展 cvt：新增 .rs 舍入模式及目标类型 .e2m1x4、.e4m3x4、.e5m2x4、.e3m2x4、.e2m3x4。
  • 扩展 st.async 与 red.async：新增 .mmio、.release、.global、.scope 限定符。
  • 扩展 tensormap.replace：.elemtype 限定符取值扩展到 13~15。
  • 扩展 mma 与 mma.sp::ordered_metadata：支持类型 .e3m2/.e2m3/.e2m1 及 .kind、.block_scale、.scale_vec_size 限定符。

语义变更与澄清

  • 澄清：在 .tile::gather4 / .tile::scatter4 模式下，张量坐标应按 {col_idx, row_idx0, row_idx1, row_idx2, row_idx3}（即 {x, y0, y1, y2, y3}）指定，而非 {x0,x1,x2,x3,y}。
  • 更新 tcgen05.mma 的指令描述符，澄清为未来预留的位。

13.7 PTX ISA 8.6 版本变更

对应架构 / CUDA 背景：随 CUDA 12.7（driver r565）。新增 sm_100（Blackwell，架构级 sm_100a）与 sm_101；引入第五代 TensorCore（tcgen05）全套指令、bulk 拷贝增强、cluster 级指令。

PTX ISA 8.6 引入以下新特性：

  • 新增 sm_100 及架构级目标 sm_100a；新增 sm_101 及架构级目标 sm_101a。
  • 扩展 cp.async.bulk 与 cp.async.bulk.tensor：新增目的状态空间 .shared::cta。
  • 扩展 fence：新增 .acquire / .release 限定符；fence 与 fence.proxy 新增 .sync_restrict。
  • 扩展 ldmatrix：支持 .m16n16、.m8n16 形状与 .b8 类型，及 .src_fmt/.dst_fmt。
  • 扩展 stmatrix：支持 .m16n8 形状与 .b8 类型。
  • 新增 clusterlaunchcontrol 指令（集群启动控制）。
  • 扩展 add/sub/fma：支持以 .f32 为目标、.f16/.bf16 为源的混合精度浮点运算。
  • 扩展 add/sub/mul/fma：支持 .f32x2 类型。
  • 扩展 cvt：.tf32 类型支持 .satfinite（配合 .rn/.rz）。
  • 扩展 cp.async.bulk：新增 .cp_mask 限定符与 byteMask 操作数。
  • 扩展 multimem.ld_reduce/multimem.st：支持 .e5m2/.e5m2x2/.e5m2x4/.e4m3/.e4m3x2/.e4m3x4 类型。
  • 扩展 cvt：支持与 .e2m1x2/.e3m2x2/.e2m3x2/.ue8m0x2 互转。
  • 扩展 bulk tensor 拷贝：新增 .tile::scatter4、.tile::gather4、.im2col::w、.im2col::w::128、.cta_group 等加载模式 / 限定符。

  • 澄清优化编译器如何处理 volatile 加载 / 存储。

13.30 PTX ISA 4.3 版本变更

对应架构 / CUDA 背景：随 CUDA 7.5（driver r352）。lop3 三输入逻辑运算、扩展精度 64 位、纹理几何扩展。

PTX ISA 4.3 引入以下新特性：

  • 新增 lop3 指令（对 3 个输入做任意逻辑运算）。
  • 扩展精度算术指令支持 64 位计算。
  • 扩展 tex.grad：支持 cube/acube 几何。
  • 扩展 tld4：支持 a2d/cube/acube 几何。
  • 扩展 tex/tld4：支持偏移向量与深度比较的可选操作数。
  • 扩展 txq：支持从指定 LOD 查询纹理字段。

语义变更与澄清

无。

13.31 PTX ISA 4.2 版本变更

对应架构 / CUDA 背景：随 CUDA 7.0（driver r346）。新增 sm_53（Maxwell 后续）；.f16/.f16x2 算术 / 纹理；surface memory_layout。

PTX ISA 4.2 引入以下新特性：

  • 新增 sm_53 目标架构。
  • 支持 .f16/.f16x2 的算术、比较与纹理指令。
  • surface 支持 memory_layout 字段，suq 可查询该字段。

语义变更与澄清

  • 更新 ABI 下参数传递语义：用于参数传递的 ld.param/st.param 不可被谓词化（predicated）。
  • 更新 {atom/red}.add.f32 语义：全局内存原子操作将次正规（subnormal）输入 / 结果刷新为符号保持的零；共享内存原子操作保留次正规，不刷新为零。

13.32 PTX ISA 4.1 版本变更

对应架构 / CUDA 背景：随 CUDA 6.5（driver r340）。新增 sm_37/sm_52（Maxwell）；纹理 / surface 新查询字段。

PTX ISA 4.1 引入以下新特性：

  • 新增 sm_37/sm_52 目标架构。
  • 纹理新增 array_size/num_mipmap_levels/num_samples 字段，txq 可查询。
  • surface 新增 array_size 字段，suq 可查询。
  • 新增特殊寄存器 %total_smem_size/%dynamic_smem_size。

语义变更与澄清

无。

13.33 PTX ISA 4.0 版本变更

对应架构 / CUDA 背景：随 CUDA 6.0（driver r331）。新增 sm_32（Maxwell 初代）/sm_50（Maxwell）；64 位性能计数器、istypep、.managed 变量。

PTX ISA 4.0 引入以下新特性：

  • 新增 sm_32/sm_50 目标架构。
  • 新增 64 位性能计数器特殊寄存器 %pm0_64..%pm7_64。
  • 新增 istypep 指令。
  • 新增 rsqrt.approx.ftz.f64 指令（平方根倒数的快速近似）。
  • 新增 .attribute 指令（指定变量特殊属性）。
  • 支持 .managed 变量属性（统一内存托管变量）。

语义变更与澄清

  • 更新 vote 语义：warp 内非活跃线程在 vote.ballot.b32 中贡献 0。

13.34 PTX ISA 3.2 版本变更

对应架构 / CUDA 背景：随 CUDA 5.5（driver r319）。多重采样纹理、调试指令增强、vavrg 语义澄清。

PTX ISA 3.2 引入以下新特性：

  • 纹理指令支持从多重采样（multisample）及多重采样数组纹理读取。
  • 扩展 .section 调试指令，纳入“标号 + 立即数”表达式。
  • 扩展 .file 指令，纳入时间戳与文件大小信息。

语义变更与澄清

  • 更新 vavrg2/vavrg4 语义：仅当 Va[i]+Vb[i] 非负时才加 1，且结果右移 1 位（而非除以 2）。

13.35 PTX ISA 3.1 版本变更

对应架构 / CUDA 背景：随 CUDA 5.0（driver r302）。新增 sm_35（Kepler 后续）；CUDA 动态并行；shf 漏斗移位；通用地址 generic()。

PTX ISA 3.1 引入以下新特性：

  • 新增 sm_35 目标架构。
  • 支持 CUDA 动态并行（kernel 内可创建并同步新工作）。
  • ld.global.nc：经非一致纹理缓存加载只读全局数据。
  • 新增漏斗移位指令 shf。
  • 扩展原子 / 归约：64 位 {and,or,xor} 与 64 位整数 {min,max}。
  • 支持 mipmaps；支持纹理 / surface 的间接访问。
  • 通用地址扩展到 .const 状态空间，新增 generic() 运算符构造通用地址。
  • 新增 .weak 指令（允许链接含同名符号的多个目标文件）。

语义变更与澄清

  • PTX 3.1 将初始化器中全局变量的默认寻址由通用地址改为全局状态空间内的偏移；旧代码视为隐式带 generic()。新代码应显式使用 generic() 或 cvta.global。
  • mad.f32 在 sm_20+ 需舍入修饰符：3.1 仅警告并默认 mad.rn.f32，3.2 起强制要求。

13.36 PTX ISA 3.0 版本变更

对应架构 / CUDA 背景：随 CUDA 4.1/4.2（driver r285/r295）。新增 sm_30（Kepler）；SIMD 视频指令、warp shuffle、mad.cc/madc、表面指令。

PTX ISA 3.0 引入以下新特性：

  • 新增 sm_30 目标架构。
  • SIMD 视频指令。
  • 新增 warp shuffle 指令。
  • mad.cc/madc 指令（高效扩展精度整数乘法）。
  • 支持 3D 与数组几何的表面（surface）指令。
  • 纹理指令支持从 cubemap 与 cubemap 数组纹理读取。
  • .target 调试平台选项（声明模块含 DWARF 调试信息）。
  • pmevent.mask（触发多个性能监视事件）。
  • 性能监视计数器特殊寄存器 %pm4..%pm7。

语义变更与澄清

  • 特殊寄存器 %gridid 由 32 位扩展到 64 位。
  • 编译到 ABI 时废弃模块级 .reg/.local 变量（不启用 ABI 时仍支持）。
  • 更新 shfl 语义：非活跃 / 被谓词关闭线程的源操作数 a 值不可预测。
  • 不再允许重复 .version 指令（原未实现，无语义变化）。
  • 移除未实现的 suld.p 与 sust.p.{u32,s32,f32}。

13.37 PTX ISA 2.3 版本变更

对应架构 / CUDA 背景：随 CUDA 4.0（driver r270）。纹理数组、.address_size 指令、.const/.global 默认零初始化。

PTX ISA 2.3 新特性：

  • 支持纹理数组（整数索引一组 1D/2D 纹理，再用浮点坐标寻址）。
  • 新增 .address_size 指令指定地址尺寸。
  • .const/.global 状态空间变量默认初始化为零。

语义变更与澄清

  • 更新 .maxntid 语义：仅保证线程块总线程数不超过最大值（不再按各维度分别强制）。
  • BFE/BFI 的 len/pos 操作数限定在 0..255。
  • 移除未实现的 {atom,red}.{min,max}.f32。

13.38 PTX ISA 2.2 版本变更

对应架构 / CUDA 背景：随 CUDA 3.2（driver r260）。内核参数属性指令、.const 扁平地址空间、tld4 指令。

PTX ISA 2.2 新特性：

  • 新增内核参数属性指令：声明参数为指针、指向的状态空间、可选对齐。
  • .samplerref 不透明类型新增字段 force_unnormalized_coords（独立纹理模式下覆盖纹理头的归一化坐标字段，供 OpenCL 等使用）。
  • 废弃显式常量 bank，.const 改用大扁平地址空间（旧 PTX 仍兼容）。
  • 新增 tld4 指令（从双线性插值覆盖的 4 个纹素中加载某分量 r/g/b/a，可用于软件高精度插值或更高带宽纹理加载）。

语义变更与澄清

无。

13.39 PTX ISA 2.1 版本变更

对应架构 / CUDA 背景：随 CUDA 3.1（driver r256）。基于栈的 ABI、间接调用、调用原型指令、%envreg 特殊寄存器。

PTX ISA 2.1 新特性：

  • sm_2x 目标支持底层基于栈的 ABI。
  • sm_2x 目标实现间接调用。
  • 新增 .branchtargets/.calltargets（间接分支 / 间接调用候选目标）、.callprototype（间接调用类型签名）。
  • 变量初始化器中可用 .global/.const 变量名表示其地址。
  • 新增 32 个驱动相关执行环境特殊寄存器 %envreg0..%envreg31。
  • 纹理 / surface 新增通道数据类型与通道顺序字段，txq/suq 可查询。
  • .minnctapersm 取代 .maxnctapersm。
  • 新增 .reqntid（指定精确的 CTA 维度）。
  • 新增 rcp.approx.ftz.f64（快速粗略倒数近似）。

语义变更与澄清

  • 若指定 .minnctapersm 而未同时指定 .maxntid，发出警告。

13.40 PTX ISA 2.0 版本变更

对应架构 / CUDA 背景：随 CUDA 3.0（driver r195）。对应 sm_20（Fermi）。目标是尽量符合 IEEE 754，同时保持与 1.x 代码的向后兼容。

浮点扩展（sm_20）

  • 单精度指令默认支持次正规数；.ftz 用于与 sm_1x 兼容。
  • 单精度 add/sub/mul 支持 .rm/.rp 舍入。
  • 新增单精度融合乘加 fma.f32（IEEE 兼容舍入，支持次正规、.ftz/.sat）；mad.f32 扩展舍入修饰符，在 sm_20 上与 fma 同义。
  • 保留不带舍入的 mad.f32 供 sm_1x 代码；在 sm_20 上映射到 fma.rn.f32。
  • 新增 IEEE 兼容舍入的单 / 双精度 div/rcp/sqrt（需 sm_20）。
  • 新增 testp 与 copysign 指令。

新增指令

  • 新增加载均匀指令 ldu。
  • surface 指令支持额外 .clamp 限定符；sust 支持格式化 surface 存储。
  • 新增 clz（前导零计数）、bfind（查找前导非符号位）、brev（位反转）、bfe/bfi（位域提取 / 插入）、popc（popcount）。
  • 新增 vote.ballot.b32。
  • 实现 {atom,red}.add.f32；sm_20 上 {atom,red}.shared 扩展到 64 位。
  • 新增系统级 membar.sys。
  • bar 扩展：bar.arrive、bar.red.popc.u32、bar.red.{and,or}.pred，支持可选线程数与寄存器操作数。
  • 新增标量视频指令（含 prmt）。
  • 新增 isspacep（查询通用地址是否落在某状态空间窗口）与 cvta（通用地址与全局 / 局部 / 共享地址互转）。

其它新特性

  • ld/ldu/st/prefetch/prefetchu/isspacep/cvta/atom/red 支持通用地址。
  • 新增特殊寄存器 %nwarpid/%nsmid/%clock64/%lanemask_{eq,le,lt,ge,gt}。
  • ld/st/suld/sust 加入缓存操作；新增 prefetch/prefetchu。
  • .maxnctapersm 废弃，改为 .minnctapersm。
  • 新增 .section 指令取代 @@DWARF 语法传递 DWARF 调试信息。
  • 新增 .pragma nounroll（禁用循环展开）。

语义变更与澄清

  • 修复 1.4 及更早 cvt.ftz 的 errata：单精度次正规不再因源/目标 64 位而漏刷新。
  • 特殊寄存器 %tid/%ntid/%ctaid/%nctaid 分量由 16 位扩展到 32 位（现为 .v4.u32）。
  • 独立纹理模式下 sampler 数从误列的 32 修正为 16。
